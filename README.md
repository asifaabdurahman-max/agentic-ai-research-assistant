 Agentic AI Research Assistant

Overview
An AI-powered research assistant built with Python and Google Gemini. It retrieves relevant Wikipedia search results and uses an AI model to generate structured research reports.

 Features
- Research question input
- Wikipedia search and source links
- Gemini-powered report generation
- Automated report structure checks
- Source summary table
- TXT and JSON report exports
- Interactive notebook interface

 Technologies
- Python
- Google Colab
- Google Gemini API
- Wikipedia API
- Requests
- Pandas
- IPyWidgets

 How It Works
1. The user enters a research question.
2. The assistant retrieves relevant Wikipedia search excerpts.
3. Gemini generates a structured report.
4. The program checks the report structure.
5. The user can export the report.

 Limitations
Search excerpts may be incomplete. Reports need human review, and the quality checks do not establish factual accuracy.
